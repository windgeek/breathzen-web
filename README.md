# BreathZen support website (moved)

BreathZen’s support and privacy pages now live on Song Li’s site:

- Support: https://songli.me/apps/breathzen/support/
- Privacy: https://songli.me/apps/breathzen/privacy/

Each language has its own page there (`…/support/zh-Hans/`, `…/privacy/ja/`, and so on).
Their source is in the private `windgeek/songli.me` repository
(`src/pages/apps/breathzen/`, content in `src/data/breathzen/`).

This repository keeps the old addresses working. `index.html` and `privacy.html`
are static redirects to the matching page on songli.me, generated by
`python3 scripts/generate.py`. The old `?lang=` and `#lang-xx` links, a saved
language choice, and the browser language still pick the matching language;
without JavaScript they go to English. GitHub Pages publishes the root of `main`.
